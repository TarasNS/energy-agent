Before the hackathon

Everything that is not building

  1. Create the repo and push

    From the unzipped folder.

    cd energy-agent
git init -b main
git add . && git commit -m "Bootstrap Energy 4.0 Harness"
gh repo create TarasNS/energy-agent --private --source=. --push
git checkout -b dev && git push -u origin dev
  2. Add names and open a team chat

    Files: TEAM.md

  3. Get an Anthropic API key for the team

    Share it privately. Each developer puts it in their own .env; it is never committed.

  4. Confirm the five decisions (30 minutes)

    With Dev 2, Dev 3 and Dev 4. Each already has a proposed answer. Freeze the schemas.

    Files: intent.md (decisions), schemas/, ARCHITECTURE.md (§9)

  5. Check the numbers with an energy colleague (15 minutes)

    Formula v1 and the demo data. Is the split by cause right? Is the data realistic?

    Files: EVALS.md (§2), data/synthetic/README.md

  6. Get the judging criteria

    Map each criterion to a moment in the demo story.

    Files: DEMO.md

  7. Send each person their page

    Link: docs/developer-N.html. Everyone clones and runs make setup before the hackathon. Dev 4 works out the golden cases.

The loop

How every task reaches dev

During the build

  1. Check dev is green after each merge

    Dev 3 posts the make verify summary. If it is red, fixing it comes first.

  2. Say no to new scope

    If it is not on someone's page, it is after the POC (PLAN.md §6).

Before presenting

  1. Confirm the end-to-end run
    make demo-smoke
make run
  2. Rehearse twice, once with Wi-Fi off

    Files: DEMO.md (rehearsal checklist)

    MODEL_PROFILE=offline make run
  3. Merge dev into main and present
    git checkout main && git merge dev && git push
