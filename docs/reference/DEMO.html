DEMO.md: the three-minute story

Owner: Lead · Role: the acceptance test for the POC. If this demo works, the POC works.

Setup: the chat page, synthetic data (2 parks, 1 battery, June 2026), server running. Offline fallback for the server: MODEL_PROFILE=offline once Dev 4's recordings (task #21) are merged. The chat page is built in Lovable and needs internet.

One-line pitch

Ask your portfolio a question, get a number you can trust, and approve the next step yourself.

30-second problem

Managers have the data, but a generic AI assistant raises three questions: Can I trust the number? Where did my data go? Can it act without me? Here, code owns the number, tools own the data, the model owns the words, and a person owns the action.

Fallback ladder

  1. No model access: run the server with MODEL_PROFILE=offline. Same loop, recorded model turns, same numbers. The Lovable page still needs internet; with no internet at all, use the screenshots.
  2. Server unreachable: run it on the presenter's laptop.
  3. Page fails: the screenshots saved in the rehearsal (task #24, Dev 2).
