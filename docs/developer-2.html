Set up

Once, before you build

  1. Open the project in Claude Code

    In the Claude desktop app, choose the Code tab and open the folder energy-agent. No folder yet? Ask Claude to clone it in the next step. The repository holds documents and checks only: that is expected.

  2. Let Claude set it up

    Claude installs the tools and runs the checks. You read the answer.

    Tell Claude

    Set up this project on my computer. If the code is not here, clone https://github.com/TarasNS/energy-agent.git. Switch to the main branch, run make setup and make check, and explain any failure in plain words. If make is not installed (common on Windows), run python scripts/dev.py setup and python scripts/dev.py check instead, and from now on read every make X in this project as python scripts/dev.py X. Do not ask me to type my API key in this chat.

    You should see: make check passed.

  3. Add the key

    Ask the lead for the Anthropic key. Copy .env.example to .env, paste the key after ANTHROPIC_API_KEY= and save. Never commit it.

    Files: .env.example

  4. Read the idea and the contract (10 minutes)

    These two files. Claude reads the rest for you. There is no harness code to copy: the team builds it together from the contract.

    Files: INTENT.md, SPEC.md
