A first proof of concept

One workflow on synthetic data, run by one small agent loop, built in one short session. It proves the number is trustworthy, the model is swappable, and actions need a human. How the harness works.

In the POC
  • Agent loop with five fixed tools
  • DK1 demo data, 15-minute prices
  • EUR by cause, from code
  • Claude explanation, swappable model
  • Proposal, human approval, audit line
  • Lovable screen, offline fallback page
After the POC
  • Eval suite and CI gating
  • Claude Code hooks
  • Live market data
  • Company data adapters

How it fits together

One request flows down. The agent loop lets the model pick the tools below it. The number on each box is the developer who builds it. Point at a name to see their part.

How every task flows

One small task, one branch, one pull request. Nothing reaches dev without a green test, a green check and a second pair of eyes.
